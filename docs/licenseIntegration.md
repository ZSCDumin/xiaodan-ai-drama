# APP 授权接入记录

版本 2.0.3，2026-10-15。本轮只接入本机授权流程，没有部署公网服务。

## 已实现

- 首页“软件授权”和设置面板可输入激活码、查看有效期与离线期限、刷新、解除设备。
- 客户端服务只信任源码固定公钥，校验 Ed25519 签名、产品、版本、设备和租约时间。页面不能修改服务地址或公钥。
- 应用服务端限制文本/媒体生成、Agent 和供应商调试入口，公共模型调用也校验授权，覆盖正常 MCP 和 Agent 调用。
- Agent 每次模型请求前重新校验，已有请求不强行截断；新生成受授权限制。普通文件操作、查看、导出和设置未加授权门槛。
- 签名离线租约最长 24 小时，每小时按需刷新；联网失败保留尚有效的原租约，服务确认拒绝后立即停止新创作。没有后台永久轮询进程。
- 刷新、激活、解除按队列串行保存，避免并发响应覆盖。普通时钟回退会阻止新创作并提示校时。
- 设备 ID 和凭证在本机服务端生成，不返回页面，不写入页面 localStorage；模型 Key 和项目内容不进入授权服务。

## 实际完成的检查

- 前后端类型检查、生产构建。
- 临时应用数据目录下，未激活的文本/媒体/Agent/临时 Agent 请求返回 402。
- 用真实签发的激活码激活，状态为 active，响应不含 deviceSecret；刷新成功。
- 激活后空生成请求进入正常参数校验（400），没有调用付费模型。
- 暂停授权服务后，主动刷新失败但已有签名租约继续有效。
- 撤销许可后刷新失败、状态 blocked，新生成返回 402，设置读取仍为 200；解除设备后回到 inactive。
- 重启应用服务读取持久化状态；浏览器检查首页入口与软件授权面板。

没有实际等待 24 小时、修改系统时钟、使用真实付费模型或完成各平台原生真机验收；不把代码分支检查当成这些场景已完成验收。

## 配置与剩余事项

apps/server/src/utils/license/config.ts 固定的是本机服务 127.0.0.1:8092 与当前本机公钥。正式部署时需换成自有 HTTPS 地址，安全迁移服务端数据库与私钥，确认公钥匹配后重新构建。Android 手机上的 127.0.0.1 指向手机自身，所以当前安装包仅供开发联调，不能交付客户作为正式授权版本。

本地应用授权状态位于 settings.json 的独立 license 字段，设置读取接口不会返回它。它包含设备凭证，当前仅由文件权限 0600 保护，仍需系统密钥库；备份或发送整个配置文件会泄露凭证，不能把它作为普通诊断附件。私钥仍只在授权服务数据目录，不随客户端分发。

有本机管理权限者仍可修改程序与文件，本实现不保证不可破解或硬件级绑定。签名校验也不能替代付款核对、售后与合法授权条款。

正式签名、默认 Android 签名密钥、第三方依赖与许可等待办仍见 commercialAudit.md。手工销售激活码与自动续费订阅是两种交付流程，未凭空增加支付商户或自动扣费。
